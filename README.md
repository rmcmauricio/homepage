# Homepage - Ricardo Maurício

Homepage moderna e responsiva para Ricardo Maurício, desenvolvedor web especializado em PHP, HTML, JavaScript, CSS e diversas tecnologias web.

**Website:** [ricardomauricio.pt](https://ricardomauricio.pt)

## 🚀 Características

- **Design Moderno**: Interface limpa e profissional com gradientes animados
- **Dark/Light Mode**: Toggle entre temas escuro e claro com persistência de preferência
- **Responsivo**: Design mobile-first que funciona perfeitamente em todos os dispositivos
- **Animações Suaves**: Animações on-scroll e transições fluidas
- **Single Page Application**: Navegação suave entre seções
- **Glassmorphism**: Efeitos de vidro modernos em elementos da interface
- **Performance Otimizada**: Código otimizado para carregamento rápido

## 📋 Seções

1. **Hero**: Banner principal com apresentação e call-to-action
2. **Sobre Mim**: Informações sobre experiência e background profissional
3. **Habilidades**: Grid com todas as tecnologias dominadas
4. **Projetos**: Portfólio de projetos desenvolvidos
5. **Contato**: Formulário de contato e informações de contato

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica moderna
- **CSS3**: 
  - Variáveis CSS para temas
  - Gradientes animados
  - Glassmorphism effects
  - Animações e transições
  - Design responsivo (mobile-first)
- **JavaScript (Vanilla)**:
  - Scroll suave
  - Toggle dark/light mode
  - Animações on-scroll (Intersection Observer)
  - Navegação ativa
  - Validação de formulário
  - Menu mobile responsivo

## 🎨 Temas

O site suporta dois temas:

- **Dark Mode** (padrão): Tema escuro moderno com gradientes vibrantes
- **Light Mode**: Tema claro elegante

A preferência do usuário é salva no localStorage do navegador.

## 🚀 Como Usar

1. Clone ou baixe o repositório
2. Abra `index.html` no navegador
3. Personalize o conteúdo conforme necessário

## 📱 Responsividade

O design é totalmente responsivo e otimizado para:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

## 🔧 Personalização

### Cores e Temas

As cores podem ser personalizadas através das variáveis CSS em `css/style.css`:

```css
:root {
    --accent-primary: #6366f1;
    --accent-secondary: #8b5cf6;
    --accent-tertiary: #ec4899;
    /* ... */
}
```

### Conteúdo

Edite o arquivo `index.html` para personalizar:
- Informações pessoais
- Descrições de habilidades
- Projetos do portfólio
- Informações de contato

### Formulário de Contato

O formulário de contato atualmente simula o envio. Para integrar com um backend:

1. Modifique a função de submit em `js/main.js`
2. Adicione a lógica de envio para seu servidor/API
3. Configure o endpoint de destino
